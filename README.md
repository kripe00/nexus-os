# NEXUS // OS — Digital Investigation & Hacking Game

An interactive OSINT detective and terminal intrusion game running inside a tactical desktop operating system in your browser.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kripe00/nexus-os.git
   cd nexus-os
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open the local URL shown in your terminal (usually `http://localhost:5173`).
